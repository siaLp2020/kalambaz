# کلمباز — بازی با کلمات

یک بازی فارسیِ رنگارنگ برای کودکان ۳ تا ۵ ساله، ساخته‌شده با React و آمادهٔ انتشار در Cloudflare Pages.

## اجرای محلی

```bash
npm install
npm run dev
```

## تست با موبایل در شبکهٔ محلی

کامپیوتر و موبایل را به یک Wi‑Fi وصل کنید. روی کامپیوتر اجرا کنید:

```bash
npm run dev:mobile
```

سپس آدرس IPv4 کامپیوتر را با `ipconfig` پیدا کنید و در مرورگر موبایل باز کنید:
`http://YOUR-PC-IP:5173` (برای این کامپیوتر: `http://192.168.122.36:5173`).

اگر Windows Firewall پرسید، دسترسی Node/Vite را فقط برای شبکهٔ Private تأیید کنید. برای تست میکروفون روی موبایل، نسخهٔ HTTPS (Cloudflare Pages یا یک HTTPS tunnel) توصیه می‌شود؛ بعضی مرورگرها میکروفون را روی HTTP شبکهٔ محلی مسدود می‌کنند.

## انتشار در Cloudflare Pages

1. این پوشه را در یک مخزن GitHub قرار دهید و به Cloudflare Pages متصل کنید.
2. تنظیمات Build را این‌طور قرار دهید: `npm run build` و پوشهٔ خروجی: `dist`.
3. در Cloudflare یک KV namespace با نام `KALAMBAZ_USERS` بسازید و آن را به پروژه bind کنید.
4. شناسهٔ namespace را در `wrangler.toml` قرار دهید (بخش کامنت‌شده را فعال کنید).
5. برای محیط staging یک branch به نام `staging` بسازید. Cloudflare برای آن Preview URL می‌سازد؛ `main` Production URL را خواهد ساخت.

بدون KV، برنامه در حالت نمایشی کار می‌کند و نام‌های یکتا را در مرورگر نگه می‌دارد. با KV، بررسی یکتایی نام در سرور Cloudflare انجام می‌شود.

## نکتهٔ حریم خصوصی

بازی هیچ فایل صدایی را ذخیره یا ارسال نمی‌کند. تشخیص گفتار فقط از قابلیت داخلی مرورگر استفاده می‌کند. برای استفاده در محیط واقعی کودک، پیش از انتشار مجوز میکروفون و سیاست حریم خصوصی را با والدین شفاف کنید.
